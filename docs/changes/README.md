# Changes for the docs team

Each lane of the 1.3 work writes `1.3-<lane>.md` here, such as `1.3-keyboard.md`, listing every change a user can see: new and changed flags, config keys, checks, messages, files and output fields, with the exact text where it matters. The docs team turns these notes into the wiki pages and the release notes, so a change that isn't listed here doesn't get documented.
